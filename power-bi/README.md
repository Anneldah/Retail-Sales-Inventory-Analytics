# Power BI Dashboard

This folder contains the Power BI report developed for the Retail Sales & Inventory Analytics project.

## Dashboard Purpose

The dashboard provides an interactive view of retail sales and inventory performance. It allows users to monitor key performance indicators, analyse sales trends, compare revenue across locations and review inventory levels.

## Key Metrics

- Total Revenue
- Total Orders
- Average Order Value
- Inventory Levels
- Sales Trends
- Revenue by City
- Product Performance

## Data Source

The Power BI report uses the processed data stored in Azure SQL Database.

The data was prepared through the project's ETL pipeline before being connected to Power BI.

## Data Model

The Power BI model connects the relevant customer, product, order and inventory data to support analysis and reporting.
