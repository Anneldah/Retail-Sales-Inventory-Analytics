# Retail Sales & Inventory Analytics – Project Overview

## Project Description

This project is an end-to-end data analytics solution designed to demonstrate how raw retail data can be collected, processed, stored, analysed and transformed into meaningful business insights.

The project uses customer, product, order and inventory datasets. The solution demonstrates data ingestion, ETL processing, SQL data transformation, data modelling and business intelligence reporting.

## Business Objective

The main objective of the project is to provide a reliable and structured data solution that allows a business to:

- Monitor sales performance
- Analyse revenue and order trends
- Understand customer and geographic performance
- Monitor product inventory
- Identify products requiring stock attention
- Support data-driven business decisions

## Technologies Used

- Azure Blob Storage
- Azure Data Factory
- Azure SQL Database
- Microsoft SQL Server / T-SQL
- Power BI
- DAX
- GitHub
- CSV datasets

## End-to-End Architecture

The solution follows the following data flow:

CSV Source Files
↓
Azure Blob Storage
↓
Azure Data Factory
↓
SQL Staging Tables
↓
Data Validation & Transformation
↓
Production SQL Tables
↓
Power BI Data Model
↓
Power BI Dashboard
↓
Business Insights

## Datasets

The project uses four main datasets:

- Customers – customer information and location data
- Products – product details, categories and pricing
- Orders – customer orders and sales transactions
- Inventory – product stock information

## Project Outcome

The final solution provides an interactive Power BI dashboard that allows users to analyse sales performance, average order value, revenue by location, product performance and inventory levels.

The project demonstrates practical experience across the complete data lifecycle, from raw data ingestion to business reporting and analysis.
